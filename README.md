## Getting Started

### Prerequisites
- Node.js 18+ installed
- npm (comes with Node.js)

### Run Locally

1. **Clone the repository**
```bash
   git clone https://github.com/ZiadTom/<repo-name>.git
   cd <repo-name>
```

2. **Install dependencies**
```bash
   npm install
```

3. **Start the development server**
```bash
   npm run dev
```

4. **Open in your browser**

### Run Locally on WIFI netowrk

- In your terminal, find your local IP
ipconfig   # Windows → look for IPv4 under your WiFi adapter

- Then on your phone (same WiFi), open:
http://192.168.x.x:3000
